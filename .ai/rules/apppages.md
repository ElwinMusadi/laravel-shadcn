# Apppages

## Authenticated page container
Halaman aplikasi terautentikasi memakai satu x-app.page-container di dalam main scroll region. Container memiliki gutter responsif dan spacing halaman, tidak boleh menjadi scroll container. Page-specific max-width berada pada child; Dashboard mempertahankan spacing block-nya sendiri.
